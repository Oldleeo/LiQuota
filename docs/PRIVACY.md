# Privacy

LiQuota 在本机运行，并通过本机 Codex App Server 读取当前账号类型、邮箱、套餐和额度窗口。

- 邮箱只用于在界面中识别账号，默认脱敏显示。
- 账号 ID、邮箱、额度响应和令牌不会写入设置文件。
- “复制额度摘要”只复制脱敏后的账号文本。
- QA 输出也只包含脱敏账号文本。
- 本机仅保存主题、窗口位置偏移和低额度提醒开关，路径为 `%LOCALAPPDATA%\LiQuota\settings.json`。
- LiQuota 本身不包含遥测、崩溃上传或自动更新网络请求。

如果未来新增联网或自动更新功能，必须在启用前清晰说明目标地址、发送字段和关闭方式。
